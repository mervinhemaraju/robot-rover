# Repository Layout — Keep CLAUDE.md in Sync

Whenever a new folder is added to the root of this repository, update the
Repository layout table in `.claude/CLAUDE.md` before finishing the task.

## What to add

A new row in the table with:

- `Path` — the folder name (e.g. `new-folder/`)
- `What it is` — one-line description of its purpose

## When this applies

- You create a new root-level folder
- The user tells you they added or are adding a new root-level folder
- You notice a root-level folder that has no entry in the table

## What counts as root-level

Only direct children of the repo root (e.g. `remote-controller/`, `docs/`).
Subfolders within those do not need table entries.
